# AutoLoc

## Présentation

AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

L'objectif du projet est de faciliter la gestion des véhicules, des locations, des clients et des différentes agences à travers une application centralisée.

## Acteurs

Les principaux acteurs identifiés sont :

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation principaux

### Client
- Consulter les véhicules disponibles
- Effectuer une demande de location
- Consulter ses locations

### Agent d'agence
- Gérer les demandes de location
- Gérer les clients
- Consulter la disponibilité des véhicules

### Responsable d'agence
- Gérer les véhicules de son agence
- Superviser les locations
- Suivre l'activité de l'agence

### Administrateur
- Gérer les utilisateurs
- Gérer les agences
- Superviser l'ensemble de la plateforme
